# PulpOS Caja — versiones para Windows

Este repositorio publica **solo los instaladores y los manifiestos de actualización firmados** de PulpOS Caja, la app de la caja para Windows. No contiene código fuente.

- **Para instalar:** descarga el instalador (`.exe`) de la última versión en [Releases](../../releases/latest). Windows puede mostrar un aviso de SmartScreen la primera vez: el equipo de PulpOS instala la app en cada comercio.
- **Actualizaciones:** la app busca sola la versión nueva al abrirse, en `latest.json` de la última versión, y la instala con la firma del equipo. No hace falta hacer nada.
- **Dudas o problemas:** escribe a `contacto@nexolabs.tech`.

Lo publica automáticamente el equipo de PulpOS al crear cada versión. Producto de NexoLabs.
